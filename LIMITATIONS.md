# Relay: Known Limitations & Operational Boundaries

1. **Current Classification**: Production-oriented prototype. Real banking/payment integrations are simulated via an explicit local sandbox action ledger.
2. **Offline Evaluation**: The default evaluation harness runs the deterministic model fake to test plumbing, schema integrity, and security abstentions without live model costs.
3. **Database Concurrency**: The default local quickstart utilizes SQLite in WAL mode; production deployments should point `DATABASE_URL` to a PostgreSQL 15+ cluster.
4. **Email Dispatch**: All email drafts generated by the model remain in draft status for human review and are not automatically dispatched to external mail servers.
